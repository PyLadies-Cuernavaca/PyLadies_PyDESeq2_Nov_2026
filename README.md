# 🐍 Análisis de Expresión Diferencial (RNA-seq) con PyDESeq2

### Taller PyLadies Cuernavaca | Noviembre 2026

Este repositorio contiene el material práctico del taller **Análisis de Expresión Diferencial (RNA-seq) con PyDESeq2**, donde aprenderemos a utilizar Python para identificar genes diferencialmente expresados a partir de datos de RNA-seq.

🕒 **Duración:** 2 horas  
💻 **Modalidad:** Práctica con Google Colab

## 🎯 Objetivos

- Comprender el flujo básico de análisis de datos RNA-seq.
- Cargar y explorar matrices de conteos.
- Realizar normalización y análisis exploratorio.
- Identificar genes diferencialmente expresados utilizando PyDESeq2.
- Interpretar los resultados estadísticos y visualizar los cambios de expresión.

## 🧬 Datos utilizados

Trabajaremos con datos públicos de RNA-seq de células **Aag2 de *Aedes aegypti*** infectadas con el virus Chikungunya (CHIKV).

**Dataset:** GSE195852  
**Fuente:** NCBI Gene Expression Omnibus (GEO).

## 🛠️ Herramientas

- Python
- Google Colab
- Pandas y NumPy
- PyDESeq2
- Matplotlib y Seaborn

## 📂 Material del taller

- `PyLadies_PyDESeq2_Nov_2026.ipynb`: notebook con explicaciones y ejercicios prácticos.
- `data/`: archivos de conteos, metadatos y anotaciones utilizados durante el análisis.

## 🚀 ¿Cómo comenzar?

1. Descarga el notebook y los archivos de datos.
2. Sube la carpeta del taller a Google Drive.
3. Abre el notebook en Google Colab.
4. Ejecuta las celdas en orden, siguiendo las instrucciones.
5. Modifica la ruta de Google Drive según la ubicación de tus archivos.

Las dependencias necesarias se instalan directamente desde el notebook.

## 📊 Análisis que realizaremos

1. Preparación de la matriz de conteos.
2. Normalización de datos.
3. Análisis exploratorio.
4. Análisis de expresión diferencial con PyDESeq2.
5. Identificación de genes sobreexpresados y subexpresados.
6. Anotación e interpretación de resultados.
